# MAYDAY · 个人宇宙

一个轻量、无需构建的个人作品网站。虚构人物「林间」与四个概念项目为演示内容。

## 本地预览

在此目录运行 `node server.cjs`，打开 `http://127.0.0.1:4317`。

## 内容修改

- `dist/app.js`：个人简介、作品、灵感、联系资料与交互。
- `dist/index.html`：首页文字、品牌、导航、页脚与页面元信息。
- `dist/styles.css`：色彩、字体、布局、动效、响应式适配。
- `dist/assets/moon.png`：通过内置 ImageGen 生成的月球视觉素材。

支持星图/列表切换、作品详情、随机漫游、灵感收藏（本地保存）、环境声音、月球彩蛋。按 `/` 或 `Ctrl/⌘ K` 打开指令菜单，空格暂停/继续轨道，Esc 关闭对话框。尊重系统减少动态效果设置。

联系邮箱 `hello@mayday.example` 为保留示例域名，使用前请替换。无后端、无统计追踪、无外部脚本依赖。
